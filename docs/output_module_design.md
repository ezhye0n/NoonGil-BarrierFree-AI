# Output Module Design

## 흐름 설계 (의사코드)

[입력]
  이미지 파일 경로를 받는다

[YOLOv12 추론]
  모델에 이미지를 넣어 추론한다
  결과로 바운딩박스 목록을 받는다
  각 박스는 (x1, y1, x2, y2, confidence, class_id) 형태

[바운딩박스 파싱]
  탐지된 박스가 없으면 "장애물 없음" 출력 후 종료
  박스가 있으면 confidence가 가장 높은 박스를 선택

[위치 판별]
  선택된 박스의 중심점 cx = (x1 + x2) / 2 계산
  이미지 너비를 3등분하여 cx가 어느 구역인지 판별
  → left / center / right 반환

[회피 방향 결정]
  zone이 left  → 우측으로 회피
  zone이 right → 좌측으로 회피
  zone이 center → 나머지 박스 중 confidence 낮은 쪽으로 회피
                  박스가 하나뿐이면 우측 기본값

[출력]
  원본 이미지에 바운딩박스 그리기
  클래스명, 회피 방향 텍스트 화면에 표시
  경사도 클래스(ramp)이면 등급(상/중/하)도 표시
  탐지된 클래스가 DANGER_CLASSES에 포함되면 TTS 음성 출력
  (DANGER_CLASSES = 전체 14개 클래스 해당, 동일 메시지 반복 시 TTS 스킵)

[저장]
  결과 이미지를 results/test_results/ 에 저장

---

## TTS 출력 기준

- 라이브러리: `edge-tts` / 음성: `ko-KR-SunHiNeural`
- 탐지된 모든 클래스에 대해 TTS 출력
- 직전 메시지와 동일한 경우 중복 출력 스킵

## 지원 클래스 및 TTS 메시지 형식

> `"전방에 {클래스명} 감지. {회피방향}"`

| 클래스 | TTS 메시지 예시 |
|--------|----------------|
| `bench` | 전방에 벤치 감지. 우측으로 우회하세요 |
| `bicycle` | 전방에 자전거 감지. 우측으로 우회하세요 |
| `bollard` | 전방에 볼라드 감지. 좌측으로 우회하세요 |

| `cone` | 전방에 라바콘 감지. 좌측으로 우회하세요 |
| `electric_scooter` | 전방에 전동킥보드 감지. 우측으로 우회하세요 |
| `fire_hydrant` | 전방에 소화전 감지. 좌측으로 우회하세요 |
| `motorcycle` | 전방에 오토바이 감지. 우측으로 우회하세요 |
