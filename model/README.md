# 🤖 Model Folder
이 폴더는 각 파트별 AI 모델의 실행 코드와 가중치(weights) 파일을 관리합니다.

- **object-detection/**: 팀원 1 (YOLOv8 기반 장애물 및 단차 탐지 코드)
- **depth-estimation/**: 팀원 2 (Depth Anything 기반 거리 추정 코드)
- **weights/**: 학습된 모델 파라미터나 가중치 파일 (.pt, .h5 등) 보관

⚠️ 주의: 모델 가중치 파일의 용량이 너무 클 경우, GitHub에 직접 올리기보다 별도의 드라이브 링크로 공유하거나 .gitignore 설정을 권장합니다.
