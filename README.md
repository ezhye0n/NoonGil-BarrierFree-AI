# 눈길(Noongil): 교통약자를 위한 배리어 프리(Barrier-Free) 내비게이션 AI

본 프로젝트는 휠체어 이용자가 안전하게 이동할 수 있도록 장애물 인식 및 도로 정보를 제공하는 AI 기반 배리어 프리 내비게이션 시스템입니다.

---

## 1. Project Overview (사회적 이슈 및 서비스 목적)

### 1) 사회적 이슈
* **인프라의 한계와 정보 비대칭:** 현대 도시의 도로에는 각종 장애물, 단차, 급경사 등 휠체어 주행을 가로막는 요소가 산재해 있습니다. 그러나 기존 지도 서비스는 일반 보행자 시점의 경로 정보만을 제공하는 **정보의 비대칭성**을 안고 있어, 휠체어 사용자에게 극심한 이동의 한계를 초래합니다.
* **행정력의 사각지대:** 지자체 차원의 보행로 정비 사업이 시행되고 있으나, 실시간으로 발생하는 장애물과 노면 파손을 인력만으로 전수 관리하기에는 예산과 행정력이 턱없이 부족한 실정입니다.
* **지형적 특수성 (효창공원 언덕길 경험):** 특히 효창공원 앞역부터 숙명여자대학교 일대의 등하교로는 가파른 경사와 불규칙한 노면 환경이 밀집해 있어 교통약자의 보행 안전을 심각하게 위협합니다. 따라서 스마트폰 카메라를 활용해 장애물의 위치와 종류를 즉각 파악하고 안전한 회피 경로를 제시하는 **AI 비전 기술이 강력한 기술적 대안**으로 대두되었습니다.

### 2) 서비스 목적
본 연구 개발은 휠체어 사용자의 주행 안전을 확보하기 위해 **휠체어 1인칭 시점의 위험 객체 탐지 및 위치 기반 최적의 회피 경로 분석 기술 개발**을 최종 목표로 합니다.
* **실측 기반 경사도 등급화:** 실제 수평계로 실측한 물리 데이터를 기반으로 경사 각도에 따른 경사도 등급(상/중/하)을 분류하고 사용자 주의 정보를 직관적으로 출력합니다.
* **다중 모듈 시스템 구축:** 안정적인 서빙을 위해 `데이터셋 구성 모듈`, `장애물 탐지 모듈(YOLO)`, `실시간 출력 모듈`로 체계를 세분화하여 개발합니다.
* **장벽 없는 UI/UX (TTS 연동):** 시각적 인지 외에도 위험 클래스 탐지 시 실시간 음성 알림(Text-to-Speech) 출력 체계를 구축하여 내비게이션의 배리어 프리 효과를 극대화합니다.

## 3. Dataset (데이터셋 구조 및 Ground Truth 실측)

다양한 물리 환경 요인에 대응하는 도메인 적응성(Domain Adaptation)을 확보 
실제 휠체어 이용자의 시야각(지면으로부터 90cm~100cm) 정밀 반영하여 직접 구축한 데이터셋의 구조와 세부 내역

### 1) 데이터 수집 구간 및 환경
* **수집 구간:** 
  * 효창공원 내부 (05.19)
  * 효창공원 앞역 ~ 숙명여자대학교 후문 (05.19 / 05.23 / 05.27 / 05.28)
  * 숙명여자대학교 내부 (05.27 / 05.28)
* **촬영 표준 가이드라인 (Data Collection Standard):**
  * 데이터의 일관성(Consistency) 유지 및 수집 단계에서의 편향(Bias) 최소화를 위해 단일 작업자(윤서연)가 동일한 폰 기종으로 촬영을 전담
  * 카메라 해상도는 3:4 비율로 고정, 데이터 왜곡 방지를 위해 자동 HDR 및 AI 보정 기능은 모두 **OFF**
  * 촬영 높이는 카메라 렌즈 기준 **지면으로부터 90cm ~ 100cm를 철저히 유지** 실제 교통약자의 Eye-level 시야각을 정밀하게 모사


### 2) 차수별 촬영 환경 및 수량 관리
다양한 기상 조건과 조도 불균형에 대응하기 위해 시계열적으로 수집 환경을 다각화
* **1차 촬영 (05.19):** 흐린 날 (16:40 ~ 17:38) ➡️ 초기 베이스 데이터 수집
* **2차 촬영 (05.23):** 쨍쨍한 날 (12:00 ~ 13:00) ➡️ 라바콘, 자전거, 가로등, 의류수거함 위주 총 44장 추가
* **3차 촬영 (05.27):** 흐린 날 (13:40 ~ 14:20) ➡️ 볼라드, 킥보드, 오토바이, 단차, 노면파손 위주 총 84장 추가
* **4차 촬영 (05.28):** 흐린 날 (12:00, 19:00) / 야간 (20:30 ~ 21:00) ➡️ 자전거, 오토바이, 라바콘, 가로등, 노면파손, 나무 위주 총 116장 추가 (**야간 저조도 데이터셋 확보**)


### 3) 클래스 ID 정의 및 정답값(Ground Truth) 물리 실측
줄자와 수평계 애플리케이션을 활용하여 물리적 수치를 직접 측정 -> 휠체어 통행 제한 장벽(단차 3cm 이상, 경사도 4° 이상)이 되는 실제 물리적 위험 요소를 검증하기 위함
가로등과 나무 클래스는 야간 조도 환경 인식률 개선을 위해 의도적으로 밤 데이터를 추가

* **ID 0: 전동킥보드** (6회 촬영)
* **ID 1: 자전거** (10회 촬영)
* **ID 2: 오토바이** (3회 촬영)
* **ID 3: 소화전** (3회 촬영)
* **ID 4: 라바콘** (4회 촬영) / **볼라드** (6회 촬영)
* **ID 5: 가로등** (총 23회 - 낮: 13회 촬영 / 밤: 10회 촬영) `*야간 조도 변화 대응`
* **ID 6: 돌벤치** (2회 촬영)
* **ID 7: 쓰레기** (3회 촬영) / **헌옷수거함** (4회 촬영)
* **ID 8: 나무** (총 7회 - 낮: 8회 촬영 / 밤: 2회 촬영) `*환경 오인식률 개선`
* **ID 9: 노면파손** (4회 촬영)
* **ID 10: 단차** (12회 촬영) 
  * *실제 줄자 측정 수치 (cm):* `3`, `4`, `4`, `4`, `6`, `7`, `9`, `10`, `10`, `11`, `12`, `12`
* **ID 12: 경사로** (7회 촬영)
  * *수평계 앱 측정 수치 (도, °):* `4°`, `6°`, `8°`, `10°`, `13°`, `14°`, `16°`


### 4) 원천 데이터 네이밍 규칙 (Data Naming Convention)
`data/raw/` 경로에 저장되는 원천 이미지는 아래 구조를 따름
물리적 회전 및 각도 변화를 부여하는 앵글 변형 기법 사용하여 데이터의 **기하학적 다양성(Geometric Diversity)**을 선제적으로 확보

> **규칙:** `[Class_ID]_[Class_Name]_[Sequence]_[Version]`
> * *예시:* `id0_electric_scooter_001_1.png`

* **`_1` (정면 촬영):** 대상 객체를 정면에서 수평으로 촬영
* **`_2` (반시계 회전):** 디바이스를 반시계로 회전하여 촬영 (물체가 우측에 치우치도록 유도)
* **`_3` (시계 회전):** 디바이스를 시계 방향으로 회전하여 촬영 (물체가 좌측에 치우치도록 유도)
* **`_4` (하향 각도):** 하이 앵글 기법 적용 (위에서 아래 방향으로 노면 파손 및 단차 각도를 부각하여 촬영)


### 5) 데이터 라벨링 및 전처리 원칙 (Roboflow)
**Roboflow** 인프라 활용하여 관리
* **Bounding Box 통일 원칙:** 객체 검출(Object Detection) 모델의 특성을 극대화하기 위해 세그멘테이션(Polygon) 방식이 아닌, **직사각형 바운딩 박스(Bounding Box)** 구조로 통일
  
| 클래스 명 (Roboflow Label) | 최종 인스턴스(BBox) 수량 |
| :--- | :--- |
| `electric_scooter` (전동킥보드) | 31 |
| `bicycle` (자전거) | 57 |
| `motorcycle` (오토바이) | 31 |
| `fire_hydrant` (소화전) | 12 |
| `cone` (라바콘) | 32 |
| `bollard` (볼라드) | 43 |
| `street_light` (가로등) | 114 |
| `bench` (돌벤치) | 16 |
| `trash` (쓰레기) | 20 |
| `clothing_bin` (헌옷수거함) | 16 |
| `tree` (나무) | 118 |
| `pavement_damage` (노면파손) | 16 |
| `step` (단차) | 50 |
| `ramp` (경사도) | 28 |

* **데이터 증강 (Data Augmentation):**
  모델의 일반화 성능을 높이고 실외 보행 환경에서의 과적합(Overfitting)을 차단하기 위해 아래 기준에 따라 데이터 증강 알고리즘을 수행

| 설정 항목 | 적용 값 | 적용 목적 |
| :--- | :--- | :--- |
| **Horizontal Flip** | 적용 (좌우 반전) | 보행 방향 및 객체 위치 편향성 해소로 데이터 다양성 확보 |
| **Rotation** | $\pm 15^\circ$ | 디바이스의 흔들림 및 다양한 도로 경사각 환경 대응 |
| **Brightness** | $\pm 15\%$ | 태양광 각도 변화 및 야간의 조도 불균형 대응 |
| **Resize** | Fit (Letterbox) 512x512 | 원본 종횡비 왜곡 없이 입력 레이어 스펙에 맞춰 최적화 |

* **데이터셋 무작위 분할 (Data Split):**
  학습 및 평가의 객관성을 보장하기 위해 정제된 데이터셋을 무작위 추출 방식을 통해 분할
  * **Train : Validation : Test = 7 : 2 : 1**
